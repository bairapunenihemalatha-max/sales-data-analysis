# Sales Data Analysis Project

## Project Overview
This project focuses on analyzing sales data to understand business performance, identify sales trends, and generate meaningful insights using Microsoft Excel.

The project includes data cleaning, calculations, KPI analysis, PivotTables, charts, and an interactive-style dashboard.

## Project Objectives
- Analyze overall sales and profit performance.
- Identify the best-performing regions.
- Compare sales across product categories.
- Understand monthly sales trends.
- Create a dashboard to present key business insights.

## Tools Used
- **Microsoft Excel** – Data cleaning, calculations, PivotTables, charts, and dashboard creation.
- **GitHub** – Project storage and portfolio presentation.

## Dataset Description
The dataset contains 500 sales records with information such as:
- Order ID
- Order Date
- Customer ID
- Customer Name
- City
- Region
- Category
- Product
- Quantity
- Unit Price
- Discount Percentage
- Unit Cost
- Segment

Additional calculated columns:
- Sales
- Profit

## Project Steps

### 1. Data Cleaning
- Checked the dataset for missing and incorrect values.
- Organized the sales data.
- Added calculated columns for Sales and Profit.

### 2. Data Analysis
Created the following Key Performance Indicators (KPIs):
- Total Sales
- Total Profit
- Total Orders
- Total Quantity
- Average Sales

### 3. PivotTable Analysis
Created PivotTables to analyze:
- Sales by Region
- Sales by Category
- Monthly Sales

### 4. Data Visualization
Created charts to present:
- Sales by Region
- Sales by Category
- Monthly Sales Trend

### 5. Dashboard
Designed a Sales Analysis Dashboard containing KPI values and charts to provide a clear view of business performance.

## Project Files
- `Dataset/` – Original and cleaned sales datasets.
- `Sales_Data_Analysis.xlsx` – Excel workbook containing data analysis, KPI summary, PivotTables, charts, and dashboard.
- `Dashboard.png` – Dashboard screenshot.
