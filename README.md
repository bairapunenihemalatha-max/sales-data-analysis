# 📊 Sales Data Analysis Using Excel

## 📌 About the Project
This is a beginner-level Data Analyst portfolio project. The main goal is to analyze sales data using Microsoft Excel and understand business performance through data analysis and visualization.

## 🎯 Project Objectives
- Analyze total sales and profit.
- Understand sales performance by region.
- Compare sales across product categories.
- Analyze monthly sales trends.
- Create a sales dashboard.

## 🛠️ Tools Used
- Microsoft Excel
- GitHub

## 📂 Dataset
The dataset contains 500 sales records with details about:
- Orders and customers
- Products and categories
- Regions and cities
- Quantity, unit price, discount, and unit cost

## 🔍 Project Workflow

1. **Data Cleaning:** Organized and prepared the sales dataset.
2. **Data Calculation:** Added Sales and Profit columns using Excel formulas.
3. **KPI Analysis:** Calculated Total Sales, Total Profit, Total Orders, Total Quantity, and Average Sales.
4. **PivotTable Analysis:** Analyzed sales by region, category, and month.
5. **Data Visualization:** Created charts to understand sales performance.
6. **Dashboard Creation:** Designed a dashboard with KPIs and charts.

## 📈 Key Performance Indicators (KPIs)
- Total Sales
- Total Profit
- Total Orders
- Total Quantity
- Average Sales

## 📊 Dashboard
The dashboard presents important sales metrics and visualizations in one place.

## 💡 Skills Learned

- Dashboard Creation
- Basic Business Analysis
